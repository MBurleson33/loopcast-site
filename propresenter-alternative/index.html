Different tools for different jobs

ProPresenter is professional presentation software for worship and live production, with lyrics, stage displays, multiple screens and much more. If you run services or productions with all of that, it’s built for you.

Plenty of screens only need a loop: a conference walk-in, a lobby TV, a booth display, a pre-service announcement loop on a second computer. For those, LoopCast is lighter and quicker to learn.

What LoopCast does

  • Loops images, PDFs and video from folders, one folder per playlist.
  • Shows a live preview of the projector, with the current and next item marked.
  • Logo screen and fade to black on one key.
  • Per-playlist endings (loop, stop or end on the logo), per-item repeat, and a manual mode to click through slides with the keyboard or a clicker.
  • Live inputs from a USB HDMI capture stick.
  • Runs offline on Windows and Mac, or in any modern browser.

What it doesn’t do

LoopCast isn’t a lyric or sermon presenter. It has no song library, stage display, timeline cues or video switching between multiple outputs. If you need those, a full presentation suite is the right tool, and LoopCast can still run the loops on a separate screen.
