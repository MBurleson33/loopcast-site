How to loop a PowerPoint or PDF on a projector.

Three ways to keep a slideshow repeating on a projector or TV, from the setting already in your presentation app to a dedicated looping player, and what to do when it stops.

Download freeOpen in your browser

1. In PowerPoint

  1. On the Transitions tab, check After and set how many seconds each slide stays up. Click Apply To All.
  2. On the Slide Show tab, choose Set Up Slide Show. Under Show type, choose Browsed at a kiosk (full screen), which also turns on Loop continuously until ‘Esc’. Under Advance slides, choose Using timings, if present.
  3. Start the slide show. It repeats until you press Esc.

If it stops on a slide, that slide has no timing: check its Transitions tab. Videos inside the deck need to be set to start automatically. More on PowerPoint kiosk mode.

2. In Keynote or Google Slides

Keynote: in the Document inspector, set the presentation type to Self-Playing, choose a delay, and check Loop slideshow.

Google Slides: start the presentation, open the options menu in the presenter toolbar, choose Auto-play, pick a speed and check Loop. Google Slides needs internet unless you’ve set it up for offline use.

These work for a single deck. They get awkward when you need video from elsewhere in the loop, more than one loop for different parts of the day, a logo screen, a countdown, or a preview of what the room sees.

3. With LoopCast

LoopCast is a free player built for this job. It loops images, PDFs and video, and gives you separate playlists, a live preview and one-key logo and black screens.

  1. Export your deck as a PDF. PowerPoint: File › Export › PDF. Keynote: File › Export To › PDF. Google Slides: File › Download › PDF. Canva: Share › Download › PDF.
  2. Put the PDF in a folder, along with any videos or images you want in the same loop. Each page of the PDF becomes a slide, drawn sharply at the projector’s resolution.
  3. Open LoopCast and choose the folder. Click Show on projector, then play. Use Fullscreen here if there’s only one screen.

Why a PDF instead of the PowerPoint file?

A PDF looks the same on every computer: no missing fonts, no “update links” prompts, no version differences between the office and the venue laptop. You lose animations and transitions inside slides, which rarely matter in a loop. If you need a video, put the video file in the folder next to the PDF instead of inside the deck.

Click through instead of auto-advance

Set a playlist’s Advance to Manual and each slide stays up until you press next: arrow keys, Page Up and Page Down, or a presentation clicker. Click any slide in the filmstrip to jump to it.

Tips for a slideshow that reads well from the back of the room

  • Use a 16:9 slide size to match most projectors and TVs.
  • Keep text large and short. Eight to ten seconds per slide is a good starting point.
  • Dark backgrounds with light text often look better on projectors, which struggle with true black-on-white contrast in a lit room.
  • For video, export MP4 (H.264). It plays everywhere.

Questions

How do I make a PowerPoint loop continuously?

Set slide timings on the Transitions tab, then Slide Show › Set Up Slide Show › Browsed at a kiosk (full screen), with Advance slides set to Using timings, if present. It loops until you press Esc.

Why does my PowerPoint stop instead of looping?

Usually a slide has no timing, or Show type isn’t set to kiosk or Loop continuously. Check each slide’s After time on the Transitions tab.

Can LoopCast open PowerPoint files?

Not directly. Export the deck as a PDF and put it in the folder; each page becomes a slide. If LoopCast finds a PowerPoint or Keynote file, it tells you how to export it.

Can I loop a PDF?

Yes. Put the PDF in a folder and choose it in LoopCast. Every page becomes a slide and the playlist repeats.

Can I mix a PDF with videos?

Yes. Put the PDF and the video files in the same folder; LoopCast plays them in one loop.
